# Mi participación y procedencia

## Trabajo grupal y asistencia

El proyecto fue universitario y grupal. Mi participación se centró en definir el comportamiento esperado, pedir y revisar ajustes y probar respuestas y el flujo de solicitudes. Utilizamos ampliamente IA para implementar código y resolver problemas; rara vez escribí el código completo de forma manual. No lo presento como desarrollo individual independiente.

La preparación local y esta presentación también tuvieron asistencia del agente: separación de configuración, laboratorio con FreeITSM, ajustes de memoria, comprobaciones y documentación. Esa preparación permite revisar el proyecto, pero no sustituye mi capacidad de explicar y repetir sus pasos.

Con este caso destaco lo que comprendí sobre RAG interno, datos, privacidad, integración de soporte y evaluación de costos. No atribuyo al equipo la creación de Ollama, FreeITSM, Qwen o BGE-M3, ni afirmo haber entrenado sus modelos.

## Recursos y referencias

- [Ollama](https://github.com/ollama/ollama): ejecución de modelos y API local.
- [Qwen2.5](https://github.com/QwenLM/Qwen2.5): familia del modelo generativo utilizado.
- [BGE-M3](https://huggingface.co/BAAI/bge-m3): modelo de embeddings para recuperación.
- [FreeITSM](https://github.com/edmozley/freeitsm): aplicación externa de mesa de ayuda. La implementación privada conserva la procedencia y licencia de su esquema.

La empresa, las políticas y el solicitante del laboratorio son ficticios. Este repositorio distribuye documentación y capturas seleccionadas, sin código de implementación, pesos de modelos, PDF completos, base de datos ni registros de conversaciones. No se añade una licencia nueva que pretenda cubrir aportes grupales o recursos de terceros.
